# **App Name**: MarketSight AI

## Core Features:

- Product Identification: Image Recognition: Uses Gemini API to automatically identify products (brand, model, type) from uploaded images.
- AI Condition Scoring: Condition Assessment: Uses AI to evaluate the product's condition (new, used, for repair, etc.) and predict price ranges.
- Market Intelligence: Market Analysis Tool: Assesses product demand, supply, and potential sales using AI. A reasoning tool uses free search data and user reviews/comments. Generates price ranges for new, used, for repair, for parts, and scrap conditions, targeting sales within 3 months. Includes a copy button for analysis levels and a model capabilities strip.
- Interactive AI Chat: Chat Interface: Allows users to ask additional questions to an AI assistant about product analysis and market data.  Includes Avatar-style buttons for model instructions.
- Inventory Management: Personal Inventory: Allows logged-in users to add, edit, and delete items in their inventory, stored in Firestore.
- Online Storefront: Product Showcase: Displays all available products for sale in a public-facing storefront, showing images, names, descriptions, and prices from Firestore.
- Shopping Cart Functionality: Shopping Cart: Allows users to add products to a cart, change quantities, remove items, and calculate the total order amount.
- Enhanced Data Integration: Adds a 'copy' button to copy different levels of the analysis. Adds a button and strip with the model's capabilities, and chat communication after each application and auto-generated data from internet searches for the same product or functionally/technically identical price range.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for trust and market analysis focus.
- Background color: Light blue (#E8EAF6), a very desaturated shade of the primary hue.
- Accent color: Purple (#7E57C2), an analogous color to the primary, used for interactive elements.
- Body and headline font: 'Inter', a grotesque sans-serif font providing a modern and objective look for both headlines and body text.
- Simple, professional icons for product categories and inventory management actions. Includes icons and emoticons.
- Clean, grid-based layout to showcase products effectively.
- Subtle transitions and animations for user interactions (e.g., adding to cart, updating inventory). Includes 'blinking' upper text for chat.
